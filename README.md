# ResumePilot

An AI-powered job application copilot that scores your resume against any job description, tailors it with AI, generates a cover letter, and tracks every application on a Kanban board.

## Tech Stack
MongoDB, Express, React, Node.js, plus an LLM for resume tailoring.

## Status
Work in progress. Backend foundation and database models are complete. Authentication is next.
